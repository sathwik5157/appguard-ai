# Local model artifacts

Generated by `python train_model.py --data Combined.xlsx`:

- `model.joblib`: fitted classifier, feature schema, label map, version, development SHAP background and input-coverage metadata.
- `metrics.json`: validation comparison, selected model test results, group-bootstrap confidence intervals, diagnostic curves, provenance, split counts, runtime and model checksum.
- `schema.json`: readable feature names and label mapping.
- `split_manifest.csv`: pattern hash, split and label for independent leakage auditing.
- `test_predictions.csv`: held-out labels, pattern hashes and probabilities for metric reproduction.

All are generated from the real supplied dataset. They are excluded from Git pending data/model sharing permission. Only load artifacts created by trusted training code. Joblib files can execute code during deserialization.
